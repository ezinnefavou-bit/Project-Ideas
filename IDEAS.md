# Project Ideas and JavaScript Practice

## Part 1: Ideas I Would Like to Work On

### Idea 1: Simple Debt Record Website for Small Shops

- Source: The problem list I prepared about common challenges faced by small Nigerian businesses, especially the problem of recording customer debts in notebooks.
- Problem: Small shop owners can lose track of how much each customer owes when they sell goods on credit.
- Who has it: Provision store owners, pharmacy owners, and boutique sellers.
- How they cope today: They write debts in notebooks and contact customers to remind them to pay.
- My possible solution: I would build a simple website where shop owners add customers, record debts and part-payments, and see the balance remaining. They could also copy a prepared reminder message to send through WhatsApp.





### Idea 2: Class Announcement and Deadline Tracker

- Source: My problem list about course announcements and deadlines getting buried in large WhatsApp groups.
- Problem: Students sometimes miss assignments, tests, and class changes because they do not see announcements in time.
- Who has it: University and polytechnic students and their course representatives.
- How they cope today: Students scroll through messages or ask classmates to repeat information, while course representatives send reminders many times.
- My possible solution: I would build a class page where course representatives post notices, test dates, and assignment deadlines. Students could see upcoming tasks in one place and mark completed tasks as done.

### Idea 3: A Duolingo-Style Tailwind CSS Learning App

- Source: My own experience learning web development and my idea of using Duolingo's short, game-like lessons as inspiration. This is my personal observation and idea, not a claim that I have interviewed users.
- Problem: Beginners can find it difficult to remember Tailwind CSS classes when they only read tutorials and do not practise them enough.
- Who has it: Beginner web developers who are learning Tailwind CSS.
- How they cope today: They watch videos, read documentation, search for class names, and copy examples while coding.
- My possible solution: I would build a learning website with short lessons, visual examples, quick challenges, and progress tracking. For example, learners could see what `bg-blue-500` does, answer a short question, and practise building a small interface before moving to the next lesson.

## My Preferred Idea

I would most like to build the Duolingo-style Tailwind CSS learning app. I chose it because it connects directly to my own learning experience as a beginner web developer. I want learning Tailwind to feel simple and practical instead of making learners read long explanations before they can practise. The app would combine short explanations, visual results, quick challenges, and revision to help learners understand and remember what each class does. I chose it over the other ideas because I can relate to the problem personally and test the first version with other beginner developers.

## The Smallest Version I Could Build in Two Weeks

For the first version, I would create five to ten short lessons about Tailwind colours, spacing, borders, and basic layout. Each lesson would have a simple explanation, a visual example, and one or two questions with feedback. The app would show lesson progress and let learners retry questions. I would leave features such as leaderboards, friend systems, and advanced accounts for later.

## One Person I Could Ask for Feedback

I would show the first version to a fellow beginner web developer or classmate who is learning Tailwind CSS. I would ask them to complete a lesson without my help, then ask which parts were clear, where they got confused, and whether the practice helped them understand the class.
