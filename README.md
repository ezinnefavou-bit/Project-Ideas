# Project Ideas and JavaScript Practice

This repository contains my answers to the Project Ideas and JavaScript Practice assignment.

## Files

- `IDEAS.md` — three project ideas, my preferred idea, a two-week first version, and a person I could ask for feedback.
- `solutions.js` — plain JavaScript solutions to all eight questions, with test examples.

## Run the JavaScript solutions

1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run:

```bash
node solutions.js
```

The debounce and retry examples use timers and asynchronous functions, so some output appears after a short wait.

## Preferred project idea

My preferred idea is a Duolingo-style Tailwind CSS learning app with short lessons, visual examples, quick challenges, and progress tracking.

## Note about research

The ideas are based on my personal experiences . Before developing the final product, I plan to speak with beginner developers and test a sample lesson to confirm what learners need.
